# CODING SAMURAI INTERNSHIP TASK

A static portfolio website built with React as part of the Coding Samurai internship program.

## 🔗 Links

- **Live App**: [suyog-shirsat2004.github.io/CODING-SAMURAI-INTERNSHIP-TASK](https://suyog-shirsat2004.github.io/CODING-SAMURAI-INTERNSHIP-TASK/)


## 🚀 Features

- Responsive design
- Component-based architecture
- Project showcase with cards
- Skills section
- Contact information and social links

## 🛠️ Built With

- **React** – UI library
- **Vite** – Build tool
- **CSS** – Styling
